# Spoox Chess v2.1

Оверлей-помощник для Chess.com на Android. Считывает доску с экрана в реальном времени, считает ходы локально через Stockfish NNUE и рисует подсказку прямо поверх партии.

## Что умеет
- Движок: нативный Stockfish NNUE (ARM64) прямо на телефоне, до 6 потоков и 128 МБ хэша. Если бинарник не подключён — автоматически работает встроенный SpooxEngine.
- Считывание экрана: автопоиск доски, калибровка под текущую тему/яркость и восстановление позиции по FEN (16×16 силуэты фигур), чтобы партия не слетала на поздних ходах.
- Только финальный ход: во время расчёта стрелка не прыгает по вариантам — показывается только итоговый ход.
- Автоход (опционально): работает без root через AccessibilityService, включается и выключается прямо в оверлее.
- Антибан-режим: MultiPV 2 с минимальным разбросом, случайные паузы перед ходом, рандомная точка нажатия внутри клетки и чередование тапов со свайпами.
- Интерфейс: Material You, 3 вкладки (Игра / Движок / Стиль), тёмная и светлая темы, 5 цветовых палитр, русский и английский языки.
